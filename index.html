SOBRE O PROJETO

Este projeto utiliza robótica, programação e sensores para realizar o monitoramento constante das condições ambientais.

O sistema coleta dados de temperatura, umidade do ar e luminosidade, comunicação em tempo real entre hardware e interface web.
